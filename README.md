# Vertex Command

A tank artillery game for graphing quadratics (Algebra 2). The tank sits at (−10, 0), so every shot passes through that point and *a* = −k ÷ (h + 10)².

- **Recruit (training range):** drag the vertex and watch *a*, vertex form, standard form, and the arc update together. The substitution for *a* is shown live. Ground targets; the shell lands at x = 2h + 10.
- **Gunner (target lock):** each arc runs through a drone. Tap a vertex, fill in *h* and *k* (*a* fills itself in), and fire. Wrong answers fly along the student's own arc.
- **Commander (solve for a):** each round has new hills, and each target has its own firing spot (flagged), some on hilltops, firing left or right. Tap a vertex and the tank drives to its spot while the student works five checked steps: write the vertex form, plug in the tank's (x, y), simplify inside the parentheses, square, subtract k, divide. Every *a* is a friendly fraction.

Single file, no build step. Direct links: `?mode=recruit`, `?mode=gunner`, `?mode=commander`.

## Deploy on GitHub Pages
1. Create a repo and add `index.html` (and this README) at the root.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `root` → Save.
3. The game goes live at `https://<username>.github.io/<repo>/`.
